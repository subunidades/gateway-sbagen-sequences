1. Exact Foundations of Matrix & Operator Inversion

  • Two-Sided Inverse: For an n × n operator/matrix A on a Hilbert space ℋ, A⁻¹ exists iff A is bijective, satisfying A · A⁻¹ = A⁻¹ · A = I.
  • Exact Invertibility Equivalences (Finite Dim.): A⁻¹ exists ⟺ det(A) ≠ 0 ⟺ rank(A) = n ⟺ 0 ∉ σ(A) (where σ(A) is the spectrum/eigenvalue set of A).
  • Adjoint Identities: With ⟨ψ, Aφ⟩ = ⟨A†ψ, φ⟩ (A† = (Ā)ᵀ), (AB)† = B†A†, (αA)† = ᾱA†, and (A⁻¹)† = (A†)⁻¹ whenever A⁻¹ exists.

2. Operator Classes in Quantum Mechanics

2.1 Unitary Operators

  • Definition: U† · U = U · U† = I (inner-product preserving & surjective).
  • Exact Inverse: U⁻¹ = U† always exists; eigenvalues satisfy |λ| = 1 and |det(U)| = 1.
  • Physical meaning: Reversible unitary evolution; conserves norm and probability.
  • Example: U(t) = exp(-iHt/ħ), U⁻¹(t) = U†(t) = exp(+iHt/ħ) (for Hermitian H).

2.2 Hermitian (Self-Adjoint) Operators

  • Definition: H† = H; spectral decomposition H = ∑_k λ_k |ψ_k⟩⟨ψ_k| with λ_k ∈ ℝ.
  • Exact Invertibility: Invertible iff 0 ∉ σ(H) (all λ_k ≠ 0), giving H⁻¹ = ∑_k (1/λ_k) |ψ_k⟩⟨ψ_k| (also Hermitian).
  • Physical meaning: Observables (energy, momentum, spin).
  • Singular Case: Any zero eigenvalue λ_k = 0 gives det(H) = 0 and non-trivial ker(H) → not invertible.

2.3 Orthogonal Projectors

  • Definition: P² = P and P† = P.
  • Eigenvalues & Invertibility: λ ∈ {0, 1} → Not invertible for any nontrivial projector (P ≠ I on full space, det(P) = 0).
  • Physical meaning: Ideal projective measurement/subspace restriction; irreversible information loss on ker(P).

2.4 Density Matrices / Operators

  • Definition: ρ† = ρ, ρ ≥ 0 (positive semidefinite, all eigenvalues p_j ≥ 0), and Tr(ρ) = 1.
  • Full-Rank Mixed State (p_j > 0 ∀j): Invertible with ρ⁻¹ = ∑_j (1/p_j) |φ_j⟩⟨φ_j|.
  • Rank-1 Pure State or Any Zero Eigenvalue: Not invertible (det(ρ) = 0; Tr(ρ²) = 1 for pure states).

3–4. Exact Matrix Calculations & Resolvent

3.1 Pauli Matrices (Involutions)

σx = [0  1; 1  0]   → det(σx) = -1
σy = [0 -i; i  0]   → det(σy) = -(-i²) = -1
σz = [1  0; 0 -1]   → det(σz) = -1

Each satisfies σ_i² = I and σ_i† = σ_i, so σ_i⁻¹ = σ_i for i ∈ {x, y, z}.

3.2 Hadamard Gate

H_had = (1/√2) [ 1  1 ]
               [ 1 -1 ]

det(H_had) = (1/2)(-1 - 1) = -1 ≠ 0. Unitary and Hermitian with H_had² = I, so H_had⁻¹ = H_had.

3.3 Pure Qubit State |0⟩⟨0|

ρ_pure = |0⟩⟨0| = [ 1  0 ]
                 [ 0  0 ]

det(ρ_pure) = 0 (eigenvalues 1, 0; rank 1) → Not invertible.

3.4 Maximally Mixed Qubit State

ρ_mixed = (1/2) I₂ = [ 1/2   0  ]
                     [  0   1/2 ]

det(ρ_mixed) = (1/2)(1/2) = 1/4 ≠ 0 → Invertible, with exact inverse ρ_mixed⁻¹ = 2I₂.

4. Green’s Function / Resolvent Operator

R_H(z) = G(z) = (zI - H)⁻¹ — Invertible on ℂ \ σ(H) whenever z ∉ σ(H) (for Hermitian H = ∑_n E_n |n⟩⟨n| and z ∉ {E_n}, (zI - H)⁻¹ = ∑_n |n⟩⟨n| / (z - E_n)). Singular whenever z ∈ σ(H) (det(zI - H) = 0).

  • Non-invertibility (det = 0, zero eigenvalue) means a non-trivial nullspace ker(A) ≠ {0}, where distinct inputs collapse to the same output and cannot be uniquely inverted.
