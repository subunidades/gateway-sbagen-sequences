Matrix Inversion in Quantum Mechanics

Foundations, operator classes, worked 2×2 examples, resolvents, and physical intuition for when operators can—and cannot—be inverted.

1. Foundations of Matrix Inversion

  • Definition: For a square matrix A, the inverse A⁻¹ satisfies A · A⁻¹ = A⁻¹ · A = I.
  • Invertibility condition: Invertible if and only if det(A) ≠ 0.
  • Relevance in quantum mechanics: Inversion represents "undoing" the action of an operator.

2. Operator Classes in Quantum Mechanics

2.1 Unitary Operators

  • Definition: U† · U = U · U† = I
  • Inverse: U⁻¹ = U†
  • Physical meaning: Reversible time evolution; conserves probability.
  • Example: U(t) = e^(-iHt/ħ), U⁻¹(t) = e^(+iHt/ħ)

2.2 Hermitian Operators

  • Definition: H† = H
  • Invertibility: Invertible iff all eigenvalues ≠ 0.
  • Physical meaning: Observables (energy, momentum, spin).
  • Examples: Pauli matrices (invertible); Hamiltonian with zero-energy eigenstates (not invertible).

2.3 Projectors

  • Definition: P² = P, P† = P
  • Eigenvalues: 0 or 1 → Not invertible.
  • Physical meaning: Measurement → information loss.

2.4 Density Matrices

  • Definition: Hermitian, positive semidefinite, Tr(ρ) = 1.
  • Mixed state (full rank): Invertible.
  • Pure state (rank-1): Not invertible.

3–4. Special Cases, Examples & Resolvent

3.1 Pauli Matrices

σx = ⎡0  1⎤    σy = ⎡0 -i⎤    σz = ⎡1  0⎤
     ⎣1  0⎦          ⎣i  0⎦          ⎣0 -1⎦

det(σx) = -1, det(σy) = 1, det(σz) = -1. Each is self-inverse: σi⁻¹ = σi.

3.2 Hadamard Gate

H = 1/√2 ⎡1  1⎤
          ⎣1 -1⎦

det(H) = -1. Self-inverse: H⁻¹ = H.

3.3 Projector |0⟩⟨0| & Pure Density Matrix

P = ρ_pure = ⎡1 0⎤
             ⎣0 0⎦

det = 0 → Not invertible.

3.4 Mixed-State Density Matrix

ρ_mixed = 1/2 ⎡1 0⎤
                ⎣0 1⎦

det(ρ) = 1/4 → Invertible, with ρ⁻¹ = 2I.

4. Green’s Functions (Resolvent)

G(z) = (zI - H)⁻¹ — Invertible whenever z is not an eigenvalue of H (z ∉ spectrum(H)). Used heavily in perturbation theory and propagators.

5–6. Quick Reference & Quantum Intuition

Operator Type Invertible? Note
Unitary Always Inverse = U†
Hermitian Sometimes Only if all eigenvalues ≠ 0
Projectors Never Measurement → information loss
Density matrices Sometimes Mixed → yes, Pure → no
Pauli matrices Always Self-inverse
Hadamard Always Self-inverse
Resolvent (zI - H)⁻¹ If z ∉ spectrum(H) Used in perturbation & propagators
  • Inversion = undoing an operation; time evolution requires unitarity.
  • Measurements collapse states, discarding information so they cannot be inverted.
